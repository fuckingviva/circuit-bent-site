Why this exists

CIRCUIT BENT started as a question: could the exact look of a circuit-bent glitch box feeding a video mixer, finished on a CRT, be captured without keeping that hardware plugged in and powered on every time it's needed.

The chain is built as a simulation instead of a filter. It runs forward in real time: tone jumps, torn frames, rolling picture and stutters keep happening for as long as the clip plays, driven by a random seed, the same way the real hardware never did quite the same thing twice.

The part that took longest wasn't the look. It was making that simulation deterministic: the same settings at the same point in the clip always render the same way, so scrubbing, rendering and re-exporting all match. A hardware glitch box never had to promise that. A plugin does.

It ships as one plugin, two templates, and a license key emailed directly after purchase. No subscription, no phone-home, no account to create.

Common questions.

Does the trial watermark my footage?
No. The 14-day trial renders at full quality. It simply stops working after 14 days unless you buy a license.
Does it need an internet connection to run?
No. License activation is offline-friendly and doesn't phone home on every launch.
Does Reactivity analyze the audio in my clip?
No. There's no audio API available to a Final Cut Pro video effect. Reactivity is a tempo pulse you set with a Hz slider, not real audio analysis, and it's labeled that way in the plugin.
Will my projects still render if I upgrade later?
Yes. Versioning follows Apple's guidance for plugin updates, so existing projects keep rendering with old versions until you choose to update.
Which hosts does it actually run in?
Final Cut Pro and Motion today. After Effects and Premiere Pro run the same real engine, Mac only for now; a Windows build doesn't exist yet.
Does CIRCUIT BENT Quick exist on every host?
No. It's a Final Cut / Motion template limited to Preset, Destruction and Mix. After Effects and Premiere use the plugin's own collapsible parameter groups instead.
